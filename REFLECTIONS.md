# Reflections

1. Share one aspect of building this project you found challenging and how you
   overcame it.

One aspect that I found challenging while building my project was having different modules instead of just 1 and finding out which functions should be imported to which module. It looks so much more organized to separate the whole code into separate files and use the import feature into main. I also learned that the import feature can be used this way to connect different files in my project, I have only used import to access the standard library for random. This project not having a lot of functions was a good starter for myself to get better with separating functions in different files knowing that in the future we may be working with projects that require so much more functions. One thing I did to better my understanding was draw out a mental model of boxes with the file names and connected them with lines to get a clear picture of which functions will be needed in which files. This helped deepen my understanding and it is something I look forward to doing in future projects  

2. Share one technical concept that you gained a deeper understanding of
   through building this project. Explain that concept in simple terms and
   explain how it is used in your project.

One technical concept I got a better understanding of by using in my project is try and except. This was really helpful in my stats functions in my code since the ZeroDivisionError shows up when calculating the win percentage with no games played yet. Try and except allows you to run your code but instead of an error showing up in the terminal that breaks the code, the except part allows python to catch that specific error and display a message instead of displaying the error.

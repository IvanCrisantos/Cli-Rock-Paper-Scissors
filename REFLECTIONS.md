# Reflections

1. Share one aspect of building this project you found challenging and how you
   overcame it.

One aspect that I found challenging while building my project was having different modules instead of just 1 and finding out which functions should be imported to which module. It looks so much more organized to separate the whole code into separate files and using the import feature into main. I also learned that the import feature can be used this way, I have only used import to access the standard library for random 

2. Share one technical concept that you gained a deeper understanding of
   through building this project. Explain that concept in simple terms and
   explain how it is used in your project.

One technical concept I got a better understanding by using in my project is try and except. This was really helpful in my stats part of the code since the ZeroDivisionError shows up when calculating the win percentage with no games played. Try and except allows you to run your code but instead of an error showing up in the terminal, the except part allows you to display a message instead of displaying the error.
